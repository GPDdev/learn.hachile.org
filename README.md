# AI 视频课堂

从一个学习问题开始，先看大纲和积分报价，再生成带中文旁白、示意动画和同步字幕的 MP4。课程默认仅作者可见，作者可以发布、撤回社区作品。预定服务地址为 `learn.hachile.org`。

## 本机运行

需要 Node.js 22.16 以上（推荐 24）、Python 3.11 以上、带 libx264 和 AAC 的 FFmpeg 与 ffprobe。Windows 本机旁白使用系统的中文语音；Linux 可安装 espeak-ng 和 Noto CJK 字体。自定义中文字体可设置 `FONT_PATH`。

```powershell
npm ci
python -m pip install -r renderer/requirements.txt
npm start
```

打开 [本机课堂](http://127.0.0.1:8787/)。启动器会应用本地数据库迁移，并一起运行 Worker 和渲染进程。关闭终端会停止本机服务，本地账号和课程保存在 `.wrangler/state`。可以用 `LEARN_PORT` 改端口，用 `LEARN_PYTHON` 指向已安装依赖的 Python。

1. 点击「登录 / 注册」，输入测试邮箱。本机页面会显示六位验证码。
2. 在工作台选择「土星环」「天文学入门」或「手写数字识别」，输入本机邀请码 `CLASSROOM`，获得 60 学习积分。
3. 查看大纲，或输入「再简短一点」「先讲第2段」改稿。确认生成后可离开页面，在「我的视频」观看实际渲染的 MP4。
4. 在播放页点击「发布到社区」，可以用未登录窗口查看。撤回后，公开播放地址也会收回访问权限。
5. 在钱包里可以体验确认、取消和查询模拟支付。本机管理员测试邮箱为 `admin@classroom.test`。以上测试入口仅在启用本机模式的回环地址生效。

默认本机模式使用三套有明确标识的示例分镜，旁白与动画在机器上生成。首次安装依赖需要网络。要测试**任意选题和自由改稿**，可在根目录私有的 `.dev.vars` 中配置本项目专用的 `DASHSCOPE_API_KEY`，然后运行 `npm start -- --cloud-models`。这个选项调用真实千问和 CosyVoice，会消耗模型额度，仍使用本机渲染和独立的本机数据库。首轮只启用一套线上数据库和一套本机付费试验库。5 元预留给本机云模型联调，45 元用于线上邀请内测，合计 50 元。离线示例无需云预算。

## 生成与发布

工作台支持领域概览和单个知识点。用户可以选择基础、修改大纲，或从成片提供的后续问题继续学习。线上千问返回结构化分镜，CosyVoice 按字幕片段合成语音，FFmpeg 以实际音频长度对齐动画和字幕，生成 H.264/AAC 视频。完成前会检查输出的音视频轨道。

社区展示已公开作品的昵称、标题、简介和成片。邮箱、原始提问及改稿内容仅用于账户和个人课程。登录用户可举报作品；管理员可在 `/admin` 查看举报并下架。有权访问者通过同源接口播放，私有 R2 桶支持断点请求。

## 积分和预算

| 事项 | 实际行为 |
| --- | --- |
| 生成报价 | 1 元兑 10 积分。每预计 6 秒 1 积分，向上取整。90 秒报 15 积分。 |
| 确认生成 | 一个大纲只创建一个任务。任务、积分预留、成本预留在同一笔数据库写入中生效。余额不足会整体回滚。 |
| 完成或失败 | 成片就绪后保留原扣款。失败或任务过期通过唯一流水原额解冻。 |
| 充值 | 提供 5、10、30 元档。正式支付宝充值进入学习余额；本机支付和支付宝沙箱进入独立测试余额。 |
| 首轮云成本 | 首轮模型及渲染总预算 50 元，线上和本机云模型试验分别限 45 元和 5 元。千问按输入上界和最大输出预留，渲染按语音文本量和 900 秒函数上限预留。 |
| 成本核算 | 成功请求按返回的 token、语音文本字节数和执行耗时估算并记录用量。费用不明时保留预留额。超过估算上界会暂停新任务。供应商账单是实际费用依据。 |

`cost_budget` 和 `costs` 控制模型与渲染预算。邮箱、视频存储与公网传输属于独立云产品费用。沙箱和生产应使用独立数据库、媒体桶和支付凭据。正式开放前按开户地域核对 `src/costs.js` 的保守费率和函数规格。内测试用使用邀请码发放的学习积分。

## 云部署

网站和同源 API 部署在独立的 Cloudflare Worker，D1 保存账户及流水，R2 存放私有视频，阿里云函数计算负责后台渲染。GitHub 托管代码和运行检查。详细命令、配置和域名切换步骤见 [部署说明](docs/deploy.md)。

### 接口

| 接口 | 用途 |
| --- | --- |
| `POST /api/auth/code`、`/api/auth/verify`、`/api/auth/invite` | 邮箱验证码、会话与内测邀请 |
| `POST /api/quotes` | 根据主题、课程类型、学习基础或上次大纲生成报价 |
| `POST /api/jobs` | 以服务端大纲 ID 确认生成 |
| `GET /api/jobs/:id`、`/api/jobs/:id/media` | 查询状态和授权播放 |
| `GET /api/library`、`/api/community` | 私人课程与公开社区 |
| `POST /api/jobs/:id/publish`、`/api/jobs/:id/report` | 发布、撤回或举报 |
| `GET /api/wallet`、`POST /api/orders`、`POST /api/orders/:id/check` | 钱包、充值及服务端查单 |
| `POST /api/payments/notify` | 支付宝 RSA2 异步通知 |

### 验证

```powershell
npm test
npm run check
python tests/check_samples.py
```

启动 `npm start` 后，可安装 Python 的 `playwright` 并运行 `python tests/browser_smoke.py`。Windows 默认使用 Edge，其他系统可通过 `LEARN_TEST_BROWSER` 指定 Chromium 程序。测试会以独立本机账号生成一条视频，验证桌面与手机播放、私有访问、发布、撤回和模拟充值。截图保存在忽略的 `.local/qa`。三个内置示例的制作脚本为 `python tools/sample_media.py`。

### 参与开发

界面在 `public`，Worker 在 `src`，追加数据库迁移放在 `migrations`，中文渲染在 `renderer`。涉及积分或公开权限的修改请同时运行账本测试和本机浏览器测试。
